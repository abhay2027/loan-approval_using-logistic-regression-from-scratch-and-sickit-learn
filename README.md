# Loan Approval Prediction Using Logistic Regression From Scratch

This project implements Logistic Regression from scratch using NumPy to predict whether a loan application should be approved or rejected based on applicant information.

The primary objective of this project was to gain a deep understanding of the mathematics and implementation details behind Logistic Regression rather than relying on pre-built machine learning libraries. Every core component of the algorithm was implemented manually, including feature normalization, the sigmoid activation function, cost calculation, gradient computation, and gradient descent optimization.

## Features

* Logistic Regression implemented from scratch using NumPy
* Z-score feature normalization
* Sigmoid activation function
* Gradient Descent optimization
* Binary classification (Approved / Rejected)
* Train-Test Split for model evaluation
* Performance comparison with Scikit-learn

## Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn (for validation only)

## Model Evaluation

The model was trained on the training set and evaluated on a separate test set to measure its ability to generalize to unseen data. The implementation achieved results comparable to Scikit-learn's LogisticRegression model, confirming the correctness of the custom implementation.
